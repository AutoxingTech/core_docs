# 2.14.12 版本更新说明

本说明列出 2.14.12 相对 2.14.11 的主要功能变化。

## 对外接口 API

1. **电池状态推送新增充电触点** - `/battery_state` 增加 `contact_touched`，表示充电触点是否已接触，上位机可据此判断是否已贴桩。

## 导航与运动控制

1. **叉车取货入栈板只纠航向** - 叉臂进入栈板后，横向位置不再按路线纠偏，只按航向对齐，横向位置交给栈板导向，减少插入过程中车身被拧歪。
2. **自动门按车身轮廓判定** - 开门区域默认按车身实际轮廓判定，只是靠近外接圆范围、实际没有碰到门区的机器人不再误开门；需要沿用外接圆判定时，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。

<BugFixes>
- 任务路线首尾重合（例如在充电桩上重新下发充电任务）时，车在起点被判为到达，零速停住且任务不结束。
- 叉车停在货位旁、只擦到货位框时，起步被禁止倒车。
- 带悬空托盘等伸出充电片的负载时，充电对接末段被判为前方有障碍，贴不上桩。
- 区域取货时列口的货挡住路线，车出列绕行后算不出路；现在与放货一致，停在轴线上等待改选空位。
- 从货架、栈板下往外开时脚下被挡住、车动不了，会一直等待不上报；现在按超时结束任务。
- 一次只开一扇自动门（`open_multiple_doors: false`）失效，同时打开了路线上的多扇门。
- 绕障算路在起点进度滞后于参考线时，有效结果被判为无效绕行而算路失败。
- 倒车段的拼接点被避障图边界截断时，路线绕进了终点附近的禁绕障区。
- 参考线超出避障图的部分保留不足，二级规划在部分场景算不出路。
- 参考线在避障图外不足两个点时，二级规划崩溃。
</BugFixes>

## 平台

1. **建图对齐方式可在 Setting 中配置** - 新增 `slam.mapping.enable_orthogonal_alignment`，可控制建图时是否自动把地图旋转到横平竖直（大部分墙与 x/y 轴平行），字段说明见 [Setting Schema](../../system-settings/parameter-system/index.md)。

## 传感器驱动

1. **蓝海（Pacecat）雷达硬件故障上报** - 雷达自身检测到的欠压、过压、机头温度异常，以及供电不足、电机堵转、测距模块过热、网络错误、测距模块无输出、系统运行异常会作为设备告警上报。
2. **麦尔威视（MRDVS）深度相机固件校验** - 固件低于 V1.1.0 或读取失败时上报设备告警，提示升级。
3. **顶升动作超时保护** - 顶升或下降持续 10 秒仍未收到停止指令时自动下发停止，避免动作一直持续。

<BugFixes>
- 华测（chcnav）RTK 连接一直保持但不再返回数据时，定位不再恢复；现在连续 5 秒无数据即重连。
</BugFixes>

## 升级注意事项

:::warning 升级前请确认

1. **自动门判定方式变更**：默认按车身轮廓精确判定，需要沿用外接圆判定的现场，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。
2. **以太网口不再带静态地址**：除 OPI4 LTS 外的主控不再为 eth0 配置 192.168.25.25，依赖该地址接入的流程需在系统网络中另行配置。
3. **叉车取货入栈板改为只纠航向**：叉臂进入栈板后不再横向纠偏，需沿用原行为时把 `/planning/dwa_v2/forks_in_pallet_heading_only` 设为 `false`；升级后先复核取货精度。

:::
