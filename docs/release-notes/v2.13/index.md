# 2.13 版本更新说明

本说明列出 2.13 相对 2.12 的主要功能变化。

## 对外接口 API

1. **新增网络与设备管理接口** - WiFi 列表与配置、路由模式、主机名、时间同步。
2. **新增货架位姿查询** - 新增 `rack_pose` 查询接口，与整车位姿查询并列。
3. **新增顶升与拖钩服务端点** - 顶升自检、拖钩锁定与释放。
4. **新增转向错误清除接口** - 可清除转向角度错误与转向零点搜索错误。
5. **新增激光雷达角度标定接口** - 支持通过接口触发激光雷达角度标定，流程见 [激光雷达标定](../../calibration/lidar-calibration/index.md)。
6. **地图接口新增信息与缩略图** - 可获取地图信息 JSON、地图缩略图，并支持从本地文件导入地图。

<BugFixes>
- 录包消息中的 NaN / Inf 浮点值导致 JSON 序列化失败。
</BugFixes>

## 导航与运动控制

1. **新增图规划模式** - 按地图拓扑的节点与路段规划，并自动生成连接主干与工位的匝道；默认仍使用原有规划器，可在设置中切换（`navigation.primary_planner`）。图模式下可配置避障开关与避障触发距离（`navigation.graph_planner.avoid_obstacles`、`obstacle_avoidance_distance`，默认 1.5 米）。
2. **新增二次路径** - 主路径不可行时自动尝试备选路线。
3. **新增货架与充电桩重入路径** - 取放货与回充时沿专用路径进出，减少反复调整。
4. **支持按给定路线行驶** - 指定路线时按地图路段规划，而不是完全自由搜索。
5. **让行改进** - 静态让行按任务类型区分触发条件；选择等待点时避开其他机器人。

<BugFixes>
- 从很窄的货架间退出时卡死。
- 大角度转向时旋转方向判断错误导致卡住。
- 无定位任务回滚到抓取位姿，而不是原地停车。
- 严格沿路线任务误触发动态让行。
- NavFn 在部分地图上规划失败。
- 非默认分辨率下膨胀层异常。
</BugFixes>

## SLAM

1. **定位模式下可配置 IMU 信任策略** - 通过 `/slam/positioning/trust_imu_mode`（`default` / `always` / `never`）决定定位时是否采信 IMU 的朝向变化。部分机器 IMU 质量偏差、零偏很不稳定，定位容易受其影响，可据此降低对 IMU 的依赖，改善定位稳定性。
2. **地图图片分辨率支持自动选择** - `/slam/slam_image_resolution` 可设为 `auto`，按 `/slam/max_auto_resolution_pixel_count` 的像素上限自动选择分辨率。几十万至上百万平方米的大场景不再按原分辨率输出图片，图片体积与打开耗时随之下降。
3. **降低 SLAM 内存占用** - 地图文件中不再保存点云，建图与加载大地图时内存占用明显下降。
4. **充电时可暂停后端优化** - 新增 `/slam/disable_optimization_when_charging`，充电期间不执行全局优化。
5. **定位状态新增数据更新时刻** - `/slam/state` 增加 `last_pose_update_time`，外部可据此判断定位数据是否新鲜。
6. **按密度删除子图时保留带约束的子图** - 批量清理子图时不再删除已有关键约束的子图，地图不易因清理而变形。

<BugFixes>
- 地图文件损坏时仍会被加载，导致建图或定位异常。
- 加载已保存的地图后仍会继续优化，地图可能被改动。
</BugFixes>

## 平台

1. **新增机型 `caracal_v3`** - 改用算力盒的 Mars 机型。
2. **新增机型 中力堆垛叉车（`forklift_zhongli_b`）** - 支持中力堆垛叉车配置。
3. **Setting Schema 支持继承** - 机型配置以基础 schema 为模板，只写差异项（`$include` / `$delete`），新增机型不必复制整份配置。详见 [参数系统](../../system-settings/parameter-system/index.md)。
4. **IMU 型号自动识别** - 上电后自动识别 MPU6050、ICM42688、ICM42688-HXY，不需要按机型手工配置。
5. **新增网络管理服务** - 提供 WiFi 扫描与配置、路由模式、主机名、时间同步（chrony）管理能力，可由上位机调用。
6. **支持按设备 SN 维护个体参数** - 单台车的差异参数集中维护，不必为个别车辆单独修改机型配置。
7. **新增停车距离设置** - `safety.stop_distance`（默认 0.5 米，可调 0.2～1.0 米）设置遇障停车距离。
8. **叉车可配置行驶中保持货叉抬起** - 新增设置项 `forklift.raise_forks_while_moving`（默认开启）。
9. **新增 IMU 陀螺信任设置** - `slam.imu.trust_gyroscope` 与 `slam.imu.trust_gyroscope_in_positioning_mode`（`default` / `always` / `never`）；修改后需重新加载地图生效。

<BugFixes>
- 云杉叉车 600 mm 机型型号名写成 `longjack_yunshan_m`，该机型取不到自己的参数。
- 以安卓板作为 NTP 源时，时间同步因等待时间过短而失败。
- 最大速度、加速度、角速度填 0 时校验仍通过，机器人无法移动；现由范围校验拒绝这类取值。
</BugFixes>

## 感知

1. **新增料笼识别** - 在料笼上成对贴 AprilTag 标签（tag36h11，默认边长 12 厘米），识别后给出料笼位姿；可用 `forward_offset` 沿料笼前方做偏移修正。
2. **货架目标位姿支持前缘中心与后缘中心** - 单货架取放与货架区识别可按前缘或后缘中心给出目标位姿。
3. **支持无间隙相邻托盘检测** - 新增 `seamless_pallet_detection`，相邻托盘紧贴时也能区分。
4. **放货位支持多帧确认** - 用多帧占据栅格确认货位占用，减少车身倾斜导致的误判。
5. **深度相机新增体素离群点剔除** - 小体素簇内的点按离群点剔除。
6. **新增 RGB 相机外参标定工具** - 可标定 RGB 相机的安装位姿。

<BugFixes>
- 充电时货叉下降后仍保留托盘识别结果，后续任务使用过期位姿。
- 双足托盘贴近墙面或其他障碍物时检测失败。
</BugFixes>

## 传感器驱动

1. **新增 Livox MID360 激光雷达驱动** - 可按机型启用。
2. **新增 Deptrum Nebular 401 深度相机** - 支持自动发现与参数下发。
3. **新增 IMU 型号 ICM42688-HXY** - 与前代型号共用同一套标定与自检流程。
4. **新增 EP 叉车充电继电器控制** - 部分充电桩在整车满电后会停止充电，节点周期性通断充电继电器以重新触发充电。
5. **BMS 通信故障时改用自算电量** - 电池管理模块异常时自动切换为自算 SOC，机器人可继续运行。
6. **Bumper GPIO 支持低电平有效** - 配置项可加 `:low` 后缀指定极性。
7. **新增升降点到点服务 `jack_move_to`** - 中力、云杉叉车可指定升降目标位置。
8. **新增陀螺零偏清除服务** - `/imu/clear_gyro_scale` 把陀螺标记为未标定，重新进入标定流程。
9. **激光量程支持整体缩放** - 新增 `range_scale` 参数，用于量程标定。
10. **底部传感器包可远程重启** - 新增服务 `/bottom_sensor_pack/restart`。

<BugFixes>
- 雷达数据中断后恢复时，扫描拼接错位。
- IMU 数据中断后继续积分姿态，触发 4004 / 4008 翻转告警。
- 手动顶升后 `/robot_model` 未更新，车体轮廓仍为旧值。
</BugFixes>

## 轮控

1. **新增软保险丝保护** - 按电流 I²t 估算发热并在超限时限制输出，避免持续推顶或顶升时过热。
2. **云杉叉车支持绝对值编码器** - 上电即可获得转向角。
3. **新增阿克曼里程计** - 前轮转向车型发布 `/ackermann_odom`。
4. **新增转向轮调试服务** - 中力叉车提供 `SteeringWheelService`，可单独控制与观测转向轮。
5. **驱动器故障码可配置连续报错次数** - `zhongli/error_report_threshold`，避免瞬时故障刷告警。
6. **急停释放前确认车轮已停** - AMPS 车型需车轮速度连续 1 秒低于 0.02 才释放。
7. **新增后向速度平滑参数** - `maxBackAcc` / `maxBackwardDecel` 单独控制倒车时的加减速。

<BugFixes>
- 起步后里程计滞后约 1 秒。
- 自动模式下 `at_top` 信号丢失时误触发下降。
</BugFixes>

## 地图与避障栅格

1. **避障栅格支持锚点配置** - `costmap_anchor_point`（默认 `base_link`），小尺寸车型可把栅格锚点设到车头中心。
2. **新增 1Hz 代价来源话题** - `/maps/5cm/1hz/source` 与 `/maps/1cm/1hz/source`。
3. **激光点云支持拖挂区域过滤** - 过滤拖挂车体覆盖范围内的激光点，避免拖挂被当成障碍。
4. **货叉尖端点云可从货位清障中排除** - `pallet_clearing_layer/exclude_fork_tips`（默认关闭）。
5. **地图服务支持大图与缩略图** - `max_image_size`（默认 8192）限制单张图片尺寸，并支持离线生成缩略图。
6. **障碍衰减只回落到未知** - 概率栅格中的障碍衰减后不再变成自由空间，避免已消失的障碍被当成可通行。

<BugFixes>
- 多个激光忽略区重叠时过滤异常。
- 手动顶升后货位区清障不生效。
</BugFixes>

## 告警

1. **新增多项故障告警** - 覆盖 IMU 读取失败、IMU 数据冻结、转向角异常、底盘控制节点未运行、传感器中枢未运行、底部传感器固件版本过低、云杉转向零点误判、电池触点接触过晚，故障可上报至监控与运维界面。

## 通信与基础库

1. **录包可配置录制参数项** - 在 `axrosbag.yaml` 中配置需要录制的参数名。
2. **录包支持重置静止计时** - 订阅 `/axrosbag/reset_last_still_time` 后重新计算静止时长。
3. **新增拖挂与视觉跟随状态消息** - `TowingState`、`TowingLockState`、`VisualFollowTarget` 等消息定义，集成方可按需订阅。

## 升级注意事项

:::warning 升级前请确认

1. **图规划默认关闭**：默认仍使用原有规划器，需要时把 `navigation.primary_planner` 改为 `graph`。
2. **障碍衰减语义变化**：衰减后的栅格只回落到未知，不再视为可通行；依赖「可通行」判定的流程需确认。
3. **地图分辨率设为 `auto` 时由系统决定实际分辨率**：依赖固定分辨率的流程需显式指定。
4. **云杉叉车支持绝对值编码器**：不具备该编码器的设备需在个体参数中排除。

:::
