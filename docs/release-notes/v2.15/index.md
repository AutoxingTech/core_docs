# 2.15 版本更新说明

本说明列出 2.15 相对 2.14 的主要功能变化。

## 对外接口 API

1. **实时推送话题支持通配符** - 话题白名单可使用 `*`、`?`（不跨层级），例如 `/detected_features/*`，新增话题不必逐条登记。
2. **新增录包回放服务** - 提供 `GET /ros/bag-player/{bags|recordings}/<包名>/{meta|index|messages}` 接口：先取整包的消息索引，再按段下发录包里的原始消息字节，不再逐条转 JSON；任何话题类型都能回放，新增消息类型不必再补转换器。
3. **任务状态新增字段** - [/planning_state](https://autoxingtech.github.io/axbot_rest_book/zh/reference/websocket-navigation.html#planning-state) 增加 `expected_cargo_action`，上位机可预判任务接下来要执行的装卸动作。

<BugFixes>
- 陀螺零偏未标定（NaN）时 `/imu_state` 整条消息不推送。
- 同名但内容不同的文件共用一份下载缓存，可能下载到旧文件；文件被截断时仍当作完整文件下发。
</BugFixes>

## 导航与运动控制

1. **货架重入改为先倒出再正向进入** - 车停在货位内再次出发时，先把车倒出货位再正向驶入，货位内不再原地掉头。
2. **交通管制支持 3D 激光雷达** - 可从 3D 点云产出语义点云与动态障碍，支持小簇噪声过滤、按地面深度限制区过滤、按高度过滤；使用 3D 雷达的车型可获得与 2D 雷达一致的动态避让与电梯占用判定。
3. **自动门改为按区域精确判定** - 开门区域默认按地图中标注的自动门区域（多边形）判定；需要沿用 2.14 的外接圆判定时，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。
4. **卸货后可直接取货** - 卸货完成后立即下发的取货指令不再被拒绝；货叉上仍载货时拒绝取货指令。

<BugFixes>
- 起点处「原地旋转 + 横移」过渡规划出错，生成的路径不可行。
- 起点附近存在死胡同单向路段时，规划出一条很长的横移路线。
- 原地旋转代价计算错误，旋转与直行路线的取舍不符合预期。
- 「禁止倒车」与「强制倒车到点」同时成立时规划失败。
- 从充电桩离站时车尾撞向桩体或周边堆垛。
- 栈板坡道被错误删除。
- 3D 激光雷达中高于车体的点被当成无回波，门框、悬空结构可能被当作可通过。
</BugFixes>

## SLAM

1. **新增定位优化暂停话题** - 外部系统可在搬运、称重等动作期间向 `/disable_slam_optimization` 发布消息暂停 SLAM 优化，最后一条消息之后 3 秒自动恢复，动作结束后不需要手工恢复。

<BugFixes>
- 调用 `/set_global_pose` 设置全局位姿后，定位没有按新的位姿立即对齐。
- 关闭全局优化后行驶一段距离就误报「定位不可靠」。
- 3D 模式下 `local_match_translation_weight` 不生效，平移约束权重调不动。
</BugFixes>

## 平台

1. **新增两款堆高叉车配置** - 在叉尖间距 600 mm 的堆高叉车之外，新增 560 mm 窄体与 680 mm 加长两种配置；整机轮廓、轴距、雷达安装位姿、顶升铁板与车高按实车实测更新。
2. **货叉接近开关接入 CAN IO** - 堆高叉车可配置左右货叉到位开关，用于判断货叉是否插入到位。

<BugFixes>
- 持续顶桩时软保险丝熔断过晚，长时间堵转得不到保护（相关机型额定电流由 42 A 下调到 30 A）。
</BugFixes>

## 感知

1. **稀疏 3D 点云下的栈板识别** - 顶边裁剪范围按栈板高度放宽，聚类半径默认提高到 0.05 m，稀疏点云也能得到完整的栈板顶边。
2. **固定货架新增朝向校验** - 检测阶段剔除朝向误差超过 10° 的结果，阈值可按机型调整。
3. **深度相机强光场景误检减少** - 按噪声水平自动提高地面判定的边缘阈值，阳光下的虚假障碍减少。

<BugFixes>
- 反光板栈板候选把前腿与后腿之后的反射配成一对，货架位姿跳变。
- 再次顶升时，缓存的栈板位姿按叉长偏移，栈板位置不准。
- 货叉位于栈板下方时取放货任务被取消或失败，识别状态被清空。
</BugFixes>

## 传感器驱动

1. **新增电动桅杆驱动** - 支持堆高叉车的电动门架升降：编码器测高、分段速度、上下限位与故障检测，桅杆节点随平台启动；未校准的状态会上报告警。
2. **新增 3D 雷达低位点过滤** - 可设置最低高度，打中货叉、叉架等低位结构的光束不再进入避障与建图（堆高叉车后向雷达已启用）。
3. **新增 Livox（览沃）MID360s 支持** - 与 MID360 同时支持，并提供 Livox SDK 1.3.1 兼容的 JSON 配置模板。
4. **蓝海（Pacecat）50C 雷达新增硬件故障上报** - 欠压、过压与雷达头部温度异常会作为设备告警上报，不再只表现为点云异常。
5. **麦尔威视（MRDVS）下视相机新增固件校验** - 固件版本不符或读取失败时上报设备告警；眩光等级可按机型配置。

<BugFixes>
- 停在充电桩上却充不进电（充电桩提前转涓流，或充满后不再自动起充）：电量低于 80% 且充电电流小于 30 A 持续 5 分钟时，自动断开继电器 15 秒强制重新起充。
- 外接 RGB 相机画面在旋转 90° 或 270° 后颜色异常。
</BugFixes>

## 地图与避障栅格

1. **新增动态禁行区服务** - [`/set_traffic_info` 与 `/get_traffic_info`](https://autoxingtech.github.io/axbot_rest_book/zh/reference/services-mapping.html#traffic-info) 可按 JSON 全量读写临时禁行区域，不重绘静态地图；重新设置地图或被清空后失效。
2. **避障图自动清除孤立噪点** - 在膨胀前清除孤立的单像素障碍（默认开启，清除强度与阈值可调），减少雷达噪点造成的虚障与误刹。

<BugFixes>
- 部分越出栅格边界的多边形区域（如禁行区）不生效。
- 放货时障碍清除区域与识别到的栈板尺寸不一致，可能残留障碍或清得过多。
</BugFixes>

## 告警

1. **新增尾板故障告警** - 尾板动作异常时上报。
2. **新增桅杆校准告警** - 桅杆零点未标定或校准失效时上报。
3. **新增内核异常告警** - 内核 Oops 与内核日志速率异常（默认 3 秒内超过 20 条）会上报；发生 OOM 杀进程时记录并上报动作事件。

## 升级注意事项

:::warning 升级前请确认

1. **`/scan_matched_points2` 移除 `probability` 字段**，只保留位置与强度；依赖该字段的流程需调整。
2. **自动门判定方式变更**：默认按地图区域精确判定，需要沿用 2.14 外接圆判定的现场，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。
3. **桅杆零点允许范围变更**：由 ±10000 tick 改为 0~81920 tick（对应 6 m 行程），现场保存的旧零点若为负值需重新校准桅杆高度。
4. **堆高叉车几何参数按实车实测更新**：轮廓、雷达位姿、轴距、顶升铁板、车高与货物到头部距离均有变化，升级后需复核取放货与停位精度。
5. **货架内离开方式变更**：车停在货位内再次出发时改为先倒出再正向驶入，需确认现场通道宽度满足倒出货位。
6. **临时禁行区不落盘**：`/set_traffic_info` 设置的临时禁行区在重新设置地图后失效，需要重新下发。

:::
