# 2.15.0 版本更新说明

本说明列出 2.15.0 相对 2.14.0 的功能变化与升级注意事项。

## 对外接口 API

1. **实时推送话题支持通配符** - 话题白名单可使用 `*`、`?`（不跨层级），例如 `/detected_features/*`，新增话题不必逐条登记。
2. **新增交通信息接口** - [`/ros/map/traffic_info`](https://autoxingtech.github.io/axbot_rest_book/zh/reference/services-mapping.html#traffic-info) 用 GET 读取、PUT 全量替换当前地图的临时禁行区。
3. **新增桅杆刻度基准标定接口** - [`/ros/jack_mast/calibrate_mast_tick_base`](https://autoxingtech.github.io/axbot_rest_book/zh/reference/services-calibration.html#calibrate-mast-tick-base) 用当前实际高度写入桅杆编码器基准值。
4. **新增陀螺标定清除接口** - [`/ros/imu/clear_gyro_scale`](https://autoxingtech.github.io/axbot_rest_book/zh/reference/services-calibration.html#clear-gyro-scale) 把陀螺标定状态标记为未标定，由设备重新标定。
5. **新增卡车装卸任务类型** - [向货车装货 / 从货车卸货](https://autoxingtech.github.io/axbot_rest_book/zh/reference/moves.html#truck-load-unload) 对应 `MOVE_TYPE_LOAD_ONTO_TRUCK` 与 `MOVE_TYPE_UNLOAD_FROM_TRUCK`。
6. **电池状态新增充电触头状态** - `/battery_state` 推送增加 `contact_touched`，可直接判断充电触头是否接触到位。
7. **任务意图改用货架出口朝向** - `/planning_intent` 新增 `current_rack_exit_yaw`（车下货架 U 形开口的朝向），取代原来的两个 via 方向字段。
8. **新增数据包流式回放接口** - [Bag Streaming API](https://autoxingtech.github.io/axbot_rest_book/zh/reference/bags.html#bag-streaming-api) 高效的二进制流式 bag 回放接口。用 HTTP 把 ROS 1 序列化字节原样返回，任意话题类型都能回放；循环录制与用户保存的两类数据包都支持。

<BugFixes>
- 陀螺零偏未标定（NaN）时 `/imu_state` 整条消息不推送。
- 同名但内容不同的文件共用一份下载缓存，可能下载到旧文件；文件被截断时仍当作完整文件下发。
</BugFixes>

## 导航与运动控制

1. **货架重入改为先倒出再正向进入** - 车停在货位内再次出发时，先把车倒出货位再正向驶入，货位内不再原地掉头。
2. **交通管制支持 3D 激光雷达** - 可从 3D 点云产出语义点云与动态障碍，支持小簇噪声过滤、按地面深度限制区过滤、按高度过滤；使用 3D 雷达的车型可获得与 2D 雷达一致的动态避让与电梯占用判定。
3. **自动门改为按区域精确判定** - 开门区域默认按地图中标注的自动门区域（多边形）判定；需要沿用 2.14 的外接圆判定时，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。
4. **卸货后可直接取货** - 卸货完成后立即下发的取货指令不再被拒绝；货叉上仍载货时拒绝取货指令。

<BugFixes>
- 起点处「原地旋转 + 横移」过渡规划出错，生成的路径不可行。
- 起点附近存在死胡同单向路段时，规划出一条很长的横移路线。
- 原地旋转代价计算错误，旋转与直行路线的取舍不符合预期。
- 「禁止倒车」与「强制倒车到点」同时成立时规划失败。
- 从充电桩离站时车尾撞向桩体或周边堆垛。
- 栈板坡道被错误删除。
- 3D 激光雷达中高于车体的点被当成无回波，门框、悬空结构可能被当作可通过。
</BugFixes>

## SLAM

1. **新增定位优化暂停话题** - 外部系统可在搬运、称重等动作期间向 `/disable_slam_optimization` 发布消息暂停 SLAM 优化，最后一条消息之后 3 秒自动恢复，动作结束后不需要手工恢复。
2. **局部与全局优化可分别关闭** - 由任务意图分别下发 `disable_localization_optimization` 与 `disable_global_optimization`，只需停一部分优化时不必整体暂停。

<BugFixes>
- 调用 `/set_global_pose` 设置全局位姿后，定位没有按新的位姿立即对齐。
- 关闭全局优化后行驶一段距离就误报「定位不可靠」。
- 3D 模式下 `local_match_translation_weight` 不生效，平移约束权重调不动。
</BugFixes>

## 平台

1. **新增两款堆高叉车配置** - 在叉尖间距 600 mm 的堆高叉车之外，新增 560 mm 窄体与 685 mm 加长两种配置；整机轮廓、轴距、雷达安装位姿、顶升铁板与车高按实车实测更新。
2. **货叉接近开关接入 CAN IO** - 堆高叉车与平衡重叉车可配置左右货叉到位开关，用于判断货叉是否插入到位。

<BugFixes>
- 持续顶桩时软保险丝熔断过晚，长时间堵转得不到保护（相关机型额定电流由 42 A 下调到 30 A）。
- CM5 设备由旧固件升级后无线热点消失，残留的旧机型网络配置现已清理。
</BugFixes>

## 感知

1. **稀疏 3D 点云下的栈板识别** - 顶边裁剪范围按栈板高度放宽，聚类半径默认提高到 0.05 m，稀疏点云也能得到完整的栈板顶边。
2. **固定货架新增朝向校验** - 检测阶段剔除朝向误差超过 10° 的结果，阈值可按机型调整。
3. **深度相机强光场景误检减少** - 按噪声水平自动提高地面判定的边缘阈值，阳光下的虚假障碍减少。
4. **卸货前确认货位是否被占用** - 用 2D 雷达点匹配货架腿结构，与避障图判定并行确认；货架摆放有偏差时不再把邻位的货架腿一并圈入。

<BugFixes>
- 反光板栈板候选把前腿与后腿之后的反射配成一对，货架位姿跳变。
- 再次顶升时，缓存的栈板位姿按叉长偏移，栈板位置不准。
- 货叉位于栈板下方时取放货任务被取消或失败，识别状态被清空。
- V 形充电桩的识别范围过大，跟踪时选中的桩体在多个候选之间跳变。
</BugFixes>

## 传感器驱动

1. **新增蓝海（Pacecat）LDS-E200-R 雷达支持** - 与同系列的 E200-E 同时支持。
2. **新增 3D 雷达低位点过滤** - 可设置最低高度，打中货叉、叉架等低位结构的光束不再进入避障与建图（堆高叉车后向雷达已启用）。
3. **新增 Livox（览沃）MID360s 支持** - 与 MID360 同时支持，并提供 Livox SDK 1.3.1 兼容的 JSON 配置模板。
4. **蓝海（Pacecat）50C 雷达新增硬件故障上报** - 欠压、过压与雷达头部温度异常会作为设备告警上报，不再只表现为点云异常。
5. **麦尔威视（MRDVS）下视相机上报型号与固件** - 型号与固件版本可在设备硬件信息中读取，固件版本不符或读取失败时上报告警。
6. **华测（chcnav）定位模块静默断流后自动重连** - TCP 连接仍存在但不再有数据时主动重连，不再卡住等待。
7. **雷达角度过滤可按段限制距离** - `angle_filter/valid_angle_ranges` 每段可加第三个值作为该段的最大距离，只屏蔽该范围内的点。

<BugFixes>
- 停在充电桩上却充不进电（充电桩提前转涓流，或充满后不再自动起充）：电量低于 80% 且充电电流小于 30 A 持续 5 分钟时，自动断开继电器 15 秒强制重新起充。
- 外接 RGB 相机画面在旋转 90° 或 270° 后颜色异常。
- IMU 数据中断后继续对旧采样积分姿态，误报 4004/4008 翻转告警。
</BugFixes>

## 轮控

<BugFixes>
- 绕过障碍后车速一直停留在障碍限速值以下，不能恢复到正常速度。
- 中力（zhongli）驱动抑制 02A016 时，把转向错误与升降超时告警一并屏蔽。
</BugFixes>

## 地图与避障栅格

1. **新增动态禁行区服务** - [`/set_traffic_info` 与 `/get_traffic_info`](https://autoxingtech.github.io/axbot_rest_book/zh/reference/services-mapping.html#traffic-info) 可按 JSON 全量读写临时禁行区域，不重绘静态地图；重新设置地图或被清空后失效。
2. **避障图自动清除孤立噪点** - 在膨胀前清除孤立的单像素障碍（默认开启，清除强度与阈值可调），减少雷达噪点造成的虚障与误刹。
3. **深度相机点云参与栈板与堆高目标清除** - 栈板与堆高目标的障碍清除同时作用于下视深度相机，对位时相机看到的货架结构不再残留为障碍。

<BugFixes>
- 部分越出栅格边界的多边形区域（如禁行区）不生效。
- 放货时障碍清除区域与识别到的栈板尺寸不一致，可能残留障碍或清得过多。
- U 形虚拟障碍的朝向与开口侧尺寸计算错误，货架开口处被多清或少清。
</BugFixes>

## 告警

1. **新增尾板故障告警** - 尾板动作异常时上报。
2. **新增桅杆校准告警** - 桅杆零点未标定或校准失效时上报。
3. **新增内核异常告警** - 内核 Oops 与内核日志速率异常（默认 3 秒内超过 20 条）会上报；发生 OOM 杀进程时记录并上报动作事件。
4. **新增蓝海（Pacecat）雷达故障告警** - 雷达上报通用故障时作为设备告警上报。

## 通信与基础库

1. **axtopic 将可打印字节显示为文本** - `UInt8Array` 类话题在字节可打印时按 ASCII 文本显示，不再只显示字节数组。

## 升级注意事项

:::warning 升级前请确认

1. **`/scan_matched_points2` 移除 `probability` 字段**，只保留位置与强度；依赖该字段的流程需调整。
2. **`/planning_intent` 移除两个 via 方向字段**，改用 `current_rack_exit_yaw`（货架 U 形开口朝向）；读取旧字段的上位机需同步调整。
3. **自动门判定方式变更**：默认按地图区域精确判定，需要沿用 2.14 外接圆判定的现场，把 `/bot_control/auto_door/geometry_mode` 设为 `coarse`。
4. **桅杆零点允许范围变更**：由 ±10000 tick 改为 0~81920 tick（对应 6 m 行程），现场保存的旧零点若为负值需重新校准桅杆高度。
5. **堆高叉车几何参数按实车实测更新**：轮廓、雷达位姿、轴距、顶升铁板、车高与货物到头部距离均有变化，升级后需复核取放货与停位精度。
6. **货架内离开方式变更**：车停在货位内再次出发时改为先倒出再正向驶入，需确认现场通道宽度满足倒出货位。
7. **临时禁行区不落盘**：`/set_traffic_info` 设置的临时禁行区在重新设置地图后失效，需要重新下发。

:::
